# homebrew-socktainer

Homebrew tap for nightly/pre-release builds of [socktainer/socktainer](https://github.com/socktainer/socktainer).

Stable releases are in [homebrew-core](https://formulae.brew.sh/formula/socktainer):

```shell
brew install socktainer
```

## Pre-release installation

```shell
brew tap socktainer/tap
brew install socktainer/tap/socktainer-next
```
